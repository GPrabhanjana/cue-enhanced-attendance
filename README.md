# CUE Enhanced Attendance

Unofficial Firefox add-on for the CHRIST University CUE portal. It shows your effective attendance and how many classes you need to hit your target, overall and per subject. It runs entirely in your browser.

## Install

Get it from **[addons.mozilla.org](https://addons.mozilla.org/firefox/addon/cue-enhanced-attendance/)** (Firefox 140+). Updates are automatic.

## What you get

- **Attendance page:**
  - *Effective attendance* (with co-curricular) and *With medical*, each shown only when it differs from the portal's figure.
  - A **Target** card that shows how many more classes you need, or how many you can skip. The default target is 85%, and you can change it.
- **View Details (per subject):** the same breakdown and Target card for that subject.

## How it counts

- **Attendance** is classes attended ÷ classes held, the same figure the portal shows.
- **Co-curricular** hours are added back.
- **Medical leave** counts only between **74.50% and 84.49%**, as the portal's rules say. Untick *Count medical* to ignore it.

## Privacy

It runs only on `cue.christuniversity.in`. It sends nothing anywhere and collects no data. Your target % is saved locally in your browser.
